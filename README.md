# HACKATHON — Fleet SOP Digitizer

Working app lives in **`fleet-digitizer`**.

```powershell
cd C:\Users\thind\OneDrive\Desktop\HACKATHON\fleet-digitizer
npm install
npm start
```

Then open **http://localhost:3847**

Or double-click `fleet-digitizer\start.cmd`.

| Folder | Purpose |
|--------|---------|
| `Templates\` | Master `.docx` / `.xlsx` forms |
| `ScannedDocs\` | Sample MFP PDF scans |
| `AutoCreatedDocs\` | Populated outputs |
| `fleet-digitizer\` | Localhost web app (see its README) |
